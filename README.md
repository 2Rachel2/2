# 한능검 퀘스트 보드

한국사능력검정시험 준비를 게임처럼 기록하는 웹 페이지입니다. 파일은 `index.html` 하나이고, 서버나 설치 없이 동작합니다.

## GitHub Pages로 공개하는 방법 (웹 화면에서)

1. github.com에 로그인하고 오른쪽 위 `+` → `New repository`를 누릅니다.
2. 이름을 적고(예: `hanneungeom-quest`), 공개 범위는 **Public**으로 선택한 뒤 `Create repository`를 누릅니다.
3. `uploading an existing file`을 눌러 `index.html`(과 `README.md`)을 끌어다 놓고 `Commit changes`를 누릅니다.
4. 저장소의 `Settings` → `Pages`로 갑니다.
5. `Build and deployment`에서 Source를 `Deploy from a branch`, Branch를 `main` / `/ (root)`로 고르고 `Save`를 누릅니다.
6. 1~2분 뒤 `https://내아이디.github.io/저장소이름/` 주소로 열립니다. 이 주소를 친구에게 보내면 됩니다.

무료 계정은 **Public** 저장소에서만 Pages를 쓸 수 있습니다.

## 사용 팁

- 기록은 각자 쓰는 기기의 브라우저에 저장됩니다. 다른 기기에서 열면 새로 시작하고, 친구의 기록은 내 기록에 섞이지 않습니다.
- 브라우저의 사이트 데이터를 지우거나 사생활 보호(시크릿) 모드로 열면 기록이 사라질 수 있습니다.
- 휴대폰에서는 브라우저 메뉴의 `홈 화면에 추가`를 누르면 앱처럼 열 수 있습니다.
- 시험일, 목표 등급, 레벨표, 퀘스트, 보상은 모두 화면에서 직접 고칠 수 있습니다.
